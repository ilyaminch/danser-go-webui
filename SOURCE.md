# Corresponding source for Danser Studio 0.4.1

The preferred source, engine sources and dependency/build metadata for this release are provided without charge as `DanserStudio-0.4.1-source.zip` beside the Windows package at:

https://github.com/ilyaminch/danser-go-webui/releases/tag/v0.4.1

The archive expands the pinned engine submodule and includes its Go dependency sources under `danser-go/vendor`, GPLv3/third-party notices, the WebUI source and lockfile, C# lazer-helper source, and build/setup scripts. Use the README development instructions and Build-Engine.ps1 / Build-LazerIndex.ps1 / Build-Package.ps1. General-purpose Go, GCC, .NET, Node and npm toolchains are not included.

Repository versions: https://github.com/ilyaminch/danser-go-webui/tree/v0.4.1 and https://github.com/ilyaminch/danser-go/tree/v0.12.0-studio.1 . The modified engine's origin is https://github.com/Wieku/danser-go . Node, .NET, Realm, FFmpeg and downloaded original runtime resources keep their individual source/license references in THIRD_PARTY_NOTICES.md and the distributed notice files.
