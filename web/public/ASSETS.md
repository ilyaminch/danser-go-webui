# Interface assets

- `fonts/nunito.ttf`: Nunito variable font, https://github.com/google/fonts/tree/main/ofl/nunito (SIL OFL, included).
- `fonts/comfortaa.ttf`: Comfortaa variable font, https://github.com/google/fonts/tree/main/ofl/comfortaa (SIL OFL, included).
- `stage-lines.svg`: original geometric artwork for Danser Studio, GPL-3.0 like the project. No upstream osu! artwork copied.
- Vinyl grooves and reflections: original procedural CSS material. Map backgrounds/audio are read from local user resources, never bundled or committed.

Fonts are self-hosted; the interface needs no external asset server.

- `fonts/exo2.ttf`: Exo 2 variable font, https://github.com/google/fonts/tree/main/ofl/exo2 (SIL OFL, included as Exo2-OFL.txt). Primary UI face; Nunito retained only as a historical bundled asset.
